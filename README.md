# Employee-Management-Using-SQL-DDL
Employee database project using SQL DDL commands, constraints, table relationships, and schema modification operations.
## 🚀 Features
- Created Employee, Department, and Location tables.
- Implemented table relationships using Foreign Keys.
- Applied database constraints to ensure data integrity.
- Performed schema modifications using DDL commands.
- Managed employee records with structured database design.
## 📂 Database Structure
### Employees Table
Stores employee information such as:
- Employee ID
- Employee Name
- Gender
- Age
- Hire Date
- Designation
- Department ID
- Location ID
- Salary
- Departments Table
Stores department information:
- Department ID
- Department Name
- Location Table
Stores location information:
- Location ID
- Location Name
## 📖 Learning Outcomes
Through this project, the following SQL concepts were practiced:
- Database creation and management
- Table relationships
- Constraint implementation
- DDL commands
- Data integrity enforcement
- Schema modification techniques
- Employee database design
## ✅ Conclusion
This project showcases the implementation of an Employee Database Management System using SQL. It demonstrates the use of DDL commands, constraints, table relationships, and schema modification techniques to build a structured and reliable database system while maintaining data consistency and integrity.
